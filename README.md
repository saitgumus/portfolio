# Portfolio — saitgumus.com

Personal site built with [Astro](https://astro.build/), [Tailwind CSS](https://tailwindcss.com/), and Markdown **Content Collections** for the blog and projects. Deployed to **Cloudflare Pages** from GitHub.

## Local development

Requirements: **Node.js 18.17+** and npm.

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:4321`).

```bash
npm run build   # production build to dist/
npm run preview # serve dist/ locally
```

## Content

| Type | Location | Notes |
|------|----------|--------|
| Blog posts | `src/content/blog/*.md` | Frontmatter: `title`, `description`, `pubDate`, optional `updatedDate`, `tags`, `draft` |
| Projects | `src/content/projects/*.md` | Frontmatter: `title`, `description`, `date`, `tags`, optional `repoUrl`, `demoUrl`, `cover`, `featured` |

- Set **`draft: true`** on a post to hide it from **production** builds and from **RSS**. Drafts are still visible when you run `npm run dev`.
- Set **`featured: true`** on a project to show it in the homepage “Featured projects” section.

## RSS and sitemap

- Feed: [`/rss.xml`](https://saitgumus.com/rss.xml) (generated from published blog posts).
- Sitemap: generated by [`@astrojs/sitemap`](https://docs.astro.build/en/guides/integrations-guide/sitemap/) at build time using `site` in `astro.config.mjs`.

## GitHub

1. Create a new repository (for example `portfolio`) on GitHub.
2. From this directory:

   ```bash
   git init
   git add .
   git commit -m "Initial portfolio site"
   git branch -M main
   git remote add origin https://github.com/saitgumus/portfolio.git
   git push -u origin main
   ```

   Replace the remote URL with your repo.

## Cloudflare Pages

1. In the Cloudflare dashboard: **Workers & Pages** → **Create** → **Pages** → **Connect to Git**.
2. Select the GitHub repository and branch (`main`).
3. Configure the build:

   | Setting | Value |
   |---------|--------|
   | Framework preset | Astro (or None) |
   | Build command | `npm run build` |
   | Build output directory | `dist` |
   | Root directory | `/` (repository root) |

4. **Environment variables (optional):** If the build image uses an old Node version, set **`NODE_VERSION`** to `20` (or `18`) in **Settings → Environment variables** for Production and Preview.

5. After the first successful deploy, open the `*.pages.dev` URL to verify the site.

## Custom domain (saitgumus.com)

1. In the Pages project: **Custom domains** → **Set up a domain**.
2. Add **`saitgumus.com`** and **`www.saitgumus.com`** as directed. If the zone is already on Cloudflare, DNS records are often created for you.
3. Pick **one canonical host** (apex or `www`) and add a **redirect** for the other:
   - **Pages:** duplicate domain entries sometimes support redirect configuration per hostname; or use **Rules** → **Redirect Rules** in the zone to send `www` → apex (or the opposite) with a **301**.
4. Wait for DNS/SSL provisioning to finish (usually minutes; propagation can take longer).

Site URL used for canonical links, RSS, and the sitemap is set in [`astro.config.mjs`](astro.config.mjs) as `site: "https://saitgumus.com"`. Change it if you standardize on `https://www.saitgumus.com` instead.
